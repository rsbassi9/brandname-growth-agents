# Brand Name Visual System

Website aesthetic signals:
- Technical archive label, not fashion boutique.
- Copy patterns: `[4DRFT]`, `// OPTICAL_SCAN: ACTIVE`, `DROP 02 / STATUS: LIVE`, `X:0027 Y:0351`, `SYSTEM_ENCRYPTED_ARCHIVE`.
- The hierarchy is stark, uppercase, system-like, and quiet.
- The product story is protocol-based: CANVAS, CAPTURE, RECONSTRUCT, DROP.

Palette:
- Bone / warm off-white background.
- Near-black text.
- Deep oxidized red accent.
- Muted grey/brown technical neutrals.
- Source artwork color should come from the raw painting, not decorative gradients.

Typography direction:
- Condensed, uppercase, utilitarian.
- Prefer bracketed labels, coordinates, protocol markers, and sparse captions.
- Avoid soft lifestyle typography, script fonts, rounded friendly UI, bubbly type, and generic streetwear poster type.

Image direction:
- Treat imagery as scan evidence, archive capture, fragment documentation, or optical reconstruction.
- Use real raw artwork/product/process assets as dominant source material.
- Generate visual concepts as editorial source images with no text embedded.
- Text overlays should be added by the dashboard/rendering layer for consistency.

Do:
- Make the image feel like a system extracting a fragment from a painting.
- Use crop, scanline, coordinate, magnification, reconstruction, and archive ideas.
- Preserve negative space and tension.
- Keep the work premium, minimal, and slightly mysterious.

Do not:
- Make generic fashion ads.
- Use neon cyberpunk, glossy AI gradients, bokeh, floating blobs, or abstract decoration.
- Generate fake readable text inside images.
- Over-style the product into a hype drop.
