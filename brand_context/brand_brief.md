# Brand Name Design Brief

Brand Name Design is an art-translation streetwear brand.

Core concept:
Physical oil painting becomes digital reconstruction, then wearable fragments.

Positioning:
This is not generic apparel. The product is a fragment of an artwork, extracted and reconstructed into a wearable object.

Voice:
- Minimal
- Intentional
- Mysterious
- Premium
- Sparse, never over-explained

Preferred language:
- Extracted
- Reconstructed
- Fragment
- Archive
- Drift
- System
- Canvas

Avoid:
- Generic fashion language
- Hype drops
- "Limited edition hoodie"
- "Stylish"
- "Check this out"
- Claims about performance data unless metrics are provided

Primary content priority:
Transformation content: canvas to digital reconstruction to wearable fragment.
