## Minimum tracking setup for tomorrow
Keep it very small and tied to the growth goal.

### Track for each post
- **Post type**: reel / carousel / image / story
- **Content pillar**: transformation / process / meaning / product
- **Hook used**: first frame or first line
- **Asset used**: painting / reconstruction / garment / body / studio / archive
- **Primary CTA**: follow / save / share / profile visit / waitlist
- **Publish time**

### Track only 6 metrics
For organic social, record these at:
- **1 hour**
- **24 hours**
- **72 hours**

Metrics:
- **Reach**
- **Likes**
- **Comments**
- **Saves**
- **Shares**
- **Profile visits**

If available, also note:
- **Follows gained from post**
- **Video watch time / retention**
- **Link clicks** or **email signups** if the post points there

### Simple score to compare posts
Use this rough priority order for this brand:
1. **Shares**
2. **Saves**
3. **Profile visits**
4. **Follows**
5. **Comments**
6. **Likes**

### Add one qualitative note per post
Write one sentence after 24 hours:
- What felt immediately legible?
- What felt confusing?
- Did the garment feel desirable?
- Did it feel like art-system first, fashion second, or the reverse?
