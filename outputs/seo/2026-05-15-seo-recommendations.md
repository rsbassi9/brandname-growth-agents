Example structure:
- **[FRAGMENT / ARCHIVE]**

- `Resolved as wearable object.`

**Collection copy should explain the system**
For collection pages, add 50–100 words describing:

**Why**

## 3) Add descriptive alt text tied to source + garment
A lot of organic image traffic is missed when alt text is absent or generic.

**Alt text format**
`[Garment name] featuring reconstructed fragment from [source painting / archive], worn in [context]`

Examples:
- `Vintage wash drop shoulder T-shirt with reconstructed fragment graphic from source painting, front view`
- `Distressed grommet eyelet tank top worn in studio light, fragment print derived from archive painting`

**Why**
- Improves image search visibility.
- Reinforces the transformation story without sounding like standard ecommerce copy.
