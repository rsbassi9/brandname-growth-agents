## 2) Strengthen product page descriptions around transformation

- Source painting reference

## 3) Collection page copy + internal linking
**Issue:** Collection pages need indexable text and clearer search intent.

**Recommendation:**
Add 2–4 lines of copy at the top or bottom of each collection page, written like a system label, not a fashion store pitch.

Example:
**Extracted from source paintings. Reconstructed into wearable fragments. Each collection is part of the same archive system.**

Then add internal links:
- Collection → related product pages
- Product pages → source painting/process pages
- Homepage → best collection + origin story page

**Organic opportunity:** This builds topical authority around the art-to-wearable system.
