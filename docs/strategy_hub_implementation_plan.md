# Strategy Hub Implementation Plan

Approval status: Draft for review

## Goal

Make the dashboard familiar with Brand Name Design's real journey, posted Instagram history, asset usage, product truth, SEO opportunities, and ad readiness while keeping publishing and spend manual.

2. Calendar reconciliation/status updates

16. Instagram Graph API sync later
17. Meta Ads read-only reporting later

## UI / UX Workflow Concept

The dashboard should work as five lanes:

- Know: Instagram memory, timeline, performance journal, asset usage, product truth.
- Plan: calendar, feed grid, launch phases, SEO opportunities, ad concepts.
- Build: post builder, creative prompts, asset swaps, copy, approval gates.
- Ship Manually: Instagram posting, Shopify SEO approval, ad launch.
- Learn: posted imports, metrics, strategist notes, weekly review.

The Strategy Hub is the control layer for this phase. It keeps dense data out of the calendar and builder while still feeding the planner context.
